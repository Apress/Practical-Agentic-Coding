# Hybrid Team Retrospective Format

A one-hour retrospective template for teams working with AI agents. Copy it into your retrospective tool and run it as written.

Why this format and when to use it: Chapter 3, Section 3.4 (Team Retrospectives).

## Agenda (60 minutes)

### 1. Collaboration analysis (15 minutes)

- Which human-agent handoffs worked well this sprint? Name the task, the person, and what made it work.
- Where did human-agent communication break down? Include code that passed review technically but violated an unwritten team convention.
- Which decisions came back to a human that you expected an agent to handle?

### 2. Performance review (15 minutes)

- Which agents beat expectations? What context, prompt, or feedback made the difference? Who should copy it?
- Which human skills mattered most this sprint (architecture calls, task decomposition, review depth)?
- Where did defects originate? Choose one for each: human oversight miss, agent limitation, or handoff gap.

### 3. Process optimization (15 minutes)

- What single workflow change would help most next sprint? Start with the human-to-agent handoff.
- Which tasks currently done by hand could an agent take over, given better tooling or context?
- What skill or capability gaps surfaced on the human side? On the agent side?

### 4. Action planning (15 minutes)

Write each output as a concrete commitment. Give each one an owner.

- [ ] Measurable improvements for next sprint, such as "use the context template for every agent task" (avoid vague items such as "communicate better")
- [ ] Agent configuration or rules-file changes to apply
- [ ] Human skill development priorities
- [ ] Tool or process changes, including rows to move in the [decision-authority matrix](decision-authority-matrix.md)

## Facilitation notes

1. Ask for specifics: which task, which prompt, what changed.
2. Keep each section to its 15 minutes.
3. Carry the action items into the next retrospective. Review them first.
