# Hybrid Team Dashboard Template

From Chapter 3, Section 3.4 (Team Velocity and Quality Metrics). This is the chapter's sprint dashboard as a fill-in template.

1. Copy the template below.
2. Fill in each blank for your sprint.

## The template

```text
Sprint __ Performance Summary

Velocity Metrics:
  - Story Points Completed: __ (target: __)
  - AI Autonomous Completion: __% of tasks
  - Human Focus Time: __% spent on high-value activities
  - Quality-Adjusted Velocity: __ points (defect penalty: __)

Quality Metrics:
  - First-Pass Code Quality: __% (target: __%)
  - Test Coverage: __% (target: __%)
  - Security Scan: __ high, __ medium issues
  - Performance Budget: __ (avg load time: __)

Collaboration Effectiveness:
  - AI Agent Response Time: __ hours average
  - Human Review Efficiency: __ minutes per AI contribution
  - Escalation Rate: __% of AI tasks (target: < 10%)
  - Team Satisfaction Score: __/10
```

## Worked example (the Sprint 23 dashboard from the book)

```text
Sprint 23 Performance Summary

Velocity Metrics:
  - Story Points Completed: 47 (target: 45)
  - AI Autonomous Completion: 65% of tasks
  - Human Focus Time: 78% spent on high-value activities
  - Quality-Adjusted Velocity: 44.1 points (defect penalty: -2.9)

Quality Metrics:
  - First-Pass Code Quality: 91% (target: 85%)
  - Test Coverage: 94% (target: 85%)
  - Security Scan: 0 high, 2 medium issues
  - Performance Budget: Within targets (1.8s avg load time)

Collaboration Effectiveness:
  - AI Agent Response Time: 1.2 hours average
  - Human Review Efficiency: 15 minutes per AI contribution
  - Escalation Rate: 8% of AI tasks (target: < 10%)
  - Team Satisfaction Score: 8.7/10
```
