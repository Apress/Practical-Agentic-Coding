# Chapter 1: What Is Agentic Coding? The Evolution Beyond AI Assistants

Chapter 1 defines agentic coding. The rest of the book builds on that definition.

## Why there is no code here

Chapter 1 is a definitional chapter. It has no listings, no configuration, and no lab. Read the chapter itself. The table below shows where later chapters turn each section into working material.

| Book section | Topic | Where the code lives |
|---|---|---|
| 1.1 | The evolution of coding assistance | Conceptual |
| 1.2 | Defining agentic coding: core characteristics | Conceptual |

| 1.4 | Agentic coding in action: real-world applications | Conceptual; worked transformations are in [chapter-13](../chapter-13/) |
| 1.5 | Beyond current capabilities: what makes this different | Conceptual |
