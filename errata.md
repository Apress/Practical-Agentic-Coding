# Errata for *Practical Agentic Coding*

Corrections to the text of *Practical Agentic Coding: Beyond Vibe Coding and AI Assistants for Successful Autonomous Software Development* by Abhijeet Patil and Manisha Patil (Apress, 2026), [ISBN 9798868826696](https://link.springer.com/book/9798868826696).

No errata currently reported.

## Reporting an error

Open an issue or submit a pull request.

- For text corrections, include the chapter, the section number, and the page if you have it.
- For code, include the file path and what you expected to happen.

## Related logs

Some differences between the book and this repo are not errors. Two other files cover them:

- [CHANGELOG.md](CHANGELOG.md): the repository's release history. Release v1.0 is the first release.
- [chapter-16/UPDATES.md](chapter-16/UPDATES.md): key industry advancements in the tools and practices the book covers (tool renames, framework releases, deprecations). Chapter 16, Section 16.7 promises this log.

Where a lab README and the book text disagree, the lab README is the tested version.
