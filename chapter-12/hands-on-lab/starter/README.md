# Starter: the TODO scaffold

**This directory is the exercise scaffold. Working solutions for every
component live in [`../complete/`](../complete/), with the same module
layout.** The finished governance pipeline is in
`../complete/governance/`.

Use this directory to build the pipeline yourself. The five modules in
`governance/` contain 42 `TODO` markers across eight components. The
components cover validators, budget, audit log, drift monitor, and
execution rail. Before you implement them, every test fails with
`NotImplementedError`. This is expected.

Work through the exercises in the order given in
[`../README.md`](../README.md). Run pytest from `hands-on-lab/` (the
parent directory):

```bash
cd ..
pytest tests/test_governance.py -v
```
