# MVP Feature Set

## Phase 1: Core Functionality (MVP)

### Must-Have Features
1. **Story Aggregation**
   - Pull from 3-5 major tech news sources
   - Fetch top stories every 30 minutes
   - Store in database with metadata

2. **Witty Summary Generation**
   - AI-generated summaries for each story
   - 2-3 sentence format
   - Consistent "witty journalist" voice

3. **Simple Feed Display**
   - Chronological list of stories
   - Show: headline, source, witty summary, link
   - Clean, readable design

4. **Basic Categorization**
   - Auto-tag stories: "Hype", "Substance", "Meh"
   - Simple algorithm based on keywords/patterns

### Nice-to-Have (Post-MVP)
- User accounts and preferences
- Voting on summary quality
- Search and filtering
- Newsletter format
- Mobile app
- Comments/discussion

## Success Metrics for MVP
- Can aggregate 50+ stories per day
- Summaries are actually witty (subjective but testable with users)
- Page loads in < 2 seconds
- Users spend > 2 minutes browsing

## MVP Timeline Estimate
- Week 1: Setup + News aggregation
- Week 2: AI summary generation
- Week 3: Frontend UI
- Week 4: Polish + Testing

## What We're NOT Building (Yet)
- User accounts
- Social features
- Mobile apps
- Advanced personalization
- Real-time notifications
