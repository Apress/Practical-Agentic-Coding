# Changelog

## v1.0: first release

The first release of the companion repository for *Practical Agentic Coding* (Apress, 2026): code examples, hands-on labs, challenge labs, tutorials, templates, and worksheets for all 16 chapters.

The labs, tutorials, and configuration files reflect each tool's documentation and releases as of November 7, 2026. Where a tool works differently from the printed book, the chapter README or the lab step says so in a note dated "As of November 7, 2026". Key industry advancements are listed in [chapter-16/UPDATES.md](chapter-16/UPDATES.md); corrections to the book's text go in [errata.md](errata.md).
