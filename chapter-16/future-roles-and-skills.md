# Future Roles and Skills: Supplement

Chapter 16, Section 16.4 of *Practical Agentic Coding* notes that roles and skills will keep evolving faster than a print edition can track. It points here for ongoing supplementary material. This page is that tracker.

The role definitions, skill descriptions, and baseline data are in the book (Sections 16.4 and 16.5). This page records only the shifts in the field beyond that baseline.

**What belongs here:**

- new role titles gaining real traction in hiring data
- meaningful changes in demand for the roles the chapter names
- new skills that become table stakes for agentic development
- shifts in how organizations structure AI-augmented teams

**Where shifts show up first:** this page checks the public sources behind Sections 16.4 and 16.5. Each entry should cite one of them or another public source.

- [Stack Overflow Developer Survey](https://survey.stackoverflow.co/): annual. The Architect figure in Section 16.5 comes from the 2025 edition. Look at each new edition first for role-mix changes.
- [Indeed Hiring Lab](https://hiringlab.indeed.com/): job-postings research. The Forward Deployed Engineer growth figure in Section 16.5 comes from Indeed postings data.
- [DORA research](https://dora.dev/research/): annual reports on how AI adoption changes team capabilities. Section 16.4 quotes the 2025 report.

**To report a shift:** open an issue or a pull request on this repository (see [Contributing.md](../Contributing.md)). Use the template below.
